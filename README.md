# DNA SEQUENCE ANALYSIS DASHBORD


## Project review 
This project is a Streamlit-based web application for analyzing DNA sequence. Users can upload Dna sequences in FASTA format and obtain basic sequence analysis'

## Feature 
-Upload DNA sequences(.fasta,.fa,.txt)
-Calculate sequence length
-Calculate GC content 
-Count nucleotides (A,T,G,C)
-Display analysis results
-Interactive and user-friendly dashboard

## Technologies Used
-Python
-Streamlit
-Pandas
-Biopython
-Matplotlib
-plotly

## How to run
1. Install the required packages: pip install -r requirement,txt
2. Run the application: streamlit run app.py

Use the provided FASTA files to test the application.
